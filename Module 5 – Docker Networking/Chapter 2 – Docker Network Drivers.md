
## Chapter 2 – Docker Network Drivers

Docker supports multiple network types.  

    
    | Driver | Purpose |
    |---------|---------|
    | Bridge | Default network for standalone containers |
    | Host | Shares host network directly |
    | None | No networking |
    | Overlay | Connects containers across multiple Docker hosts |
    | Macvlan | Gives containers their own MAC/IP on the physical network |
